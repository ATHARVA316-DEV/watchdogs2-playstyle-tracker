# Files Explained

Here is a breakdown of what every file in this directory does:

### Core Python Scripts
* **`input_logger.py`**: A background script that monitors your keyboard and mouse inputs (WASD, clicks, etc.) while you play. It uses this to estimate your time spent in different states (Driving, Combat, Stealth).
* **`ocr_capture.py`**: A screen capture script that uses Tesseract OCR to read the "Mission Complete" stat screen in Watch Dogs 2. It grabs raw numbers for Kills, Headshots, Hacks, etc., and saves them as JSON sessions.
* **`stat_engine.py`**: The "brain" of the project. It reads all the JSON files in the `sessions/` folder, averages out your stats over time, determines your Playstyle Archetype (e.g. Netrunner, Aggressor), and compiles everything into `card_data.json`.
* **`build_card_dynamic.py`**: Reads `card_data.json` and injects it into a massive HTML string containing React, Babel, and CSS. It then writes the final output to `index.html`.
* **`build_card.py`**: An older/legacy version of the card builder. (Kept for reference).
* **`manual_tagger.py`**: A utility script that allows you to manually review and tag/edit older session files if they were recorded incorrectly.
* **`seed_sessions.py`**: A developer utility script that generates fake, randomized session data to test the `stat_engine.py` and the HTML card without having to play the game.

### Data & Configuration Files
* **`requirements.txt`**: A text file listing all the Python dependencies required to run this project (e.g., `pytesseract`, `keyboard`, `rich`).
* **`card_data.json`**: The final, processed JSON file generated by `stat_engine.py`. It contains your summarized stats and archetype. *(Ignored in `.gitignore` to keep your data private).*
* **`ocr_regions.json`**: A configuration file created when you run `ocr_capture.py --calibrate`. It stores the X/Y coordinates of where stats are located on your specific monitor. *(Ignored in `.gitignore`).*
* **`keybinds.json`**: Contains custom keybinds for the logger, if modified.

### Web / UI Files
* **`index.html`**: The final, generated web page that displays your Playstyle Card. You open this in your browser. *(Ignored in `.gitignore` as it is an auto-generated build file).*
* **`PlayerCard.jsx`**: A raw React component file that contains the layout for the web page. The contents of this are injected into `index.html` via the build script.

### Directories
* **`sessions/`**: The folder where all raw data captures (from the logger and OCR) are saved as JSON files. *(Ignored in `.gitignore`).*
* **`captures/`**: The folder where raw screenshots taken by the OCR script are temporarily stored. *(Ignored in `.gitignore`).*
